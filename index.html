See what's eating your disk. Delete it safely.

ZerX finds the dev caches, build artifacts and hidden folders Finder never shows — node_modules, DerivedData, package caches, simulator images — and lets you tick what goes to the Trash. Nothing else.

macOS 13 or later · Apple Silicon and Intel · Free · Notarized by Apple

Built for people who have a node_modules problem

  • Sees what Finder hides

    Hidden dev folders, package manager caches, DerivedData, worktrees left by AI agents, Docker images, simulators. A full 250 GB home folder scans in about 15 seconds.

  • Trash first, never past it

    Everything you delete goes to the Trash by default. Keychains, Mail, Photos, iCloud, SSH keys and system files are off-limits at the architecture level, not just hidden in the UI.

  • Knows which projects are alive

    Projects with recent commits or edits are never pre-selected. If you pick something inside one, ZerX tells you before it moves.

  • No telemetry, no account, no network

    The app never phones home. The update check is off by default and, when you turn it on, talks only to zerxapp.com to read a list of versions.

Four steps, no wizard

  1. Grant Full Disk Access

    macOS needs it to let ZerX see caches inside ~/Library. ZerX shows you exactly where to click.

  2. Scan

    Your home folder plus system caches, sized like Finder does it. Numbers tick while it runs.

  3. Review and tick

    Dev caches and old build artifacts are pre-selected when it's safe. Everything else is your call.

  4. Delete to Trash

    Empty the Trash when you're sure. Local Time Machine snapshots can go too, with an admin prompt.

Three layers between you and a bad day

  • Scope allowlist

    Only your home folder, /tmp and /Users/Shared can be touched. The rest of the disk is shown for the picture, not for deletion.

  • Hard blocklist

    Keychains, Preferences, Application Support, iCloud, Messages, Mail, Photos, Safari, .ssh, .gnupg, .aws, .kube, shell rc files. Any folder containing a protected path is protected too.

  • One gate

    Every deletion passes through a single checkpoint that normalizes the path and re-checks it after resolving symlinks. A symlink into a protected folder doesn't get through. Covered by tests.

Install

Download the DMG, drag ZerX to Applications, open it. Gatekeeper accepts it: the app is signed with a Developer ID and notarized by Apple.

Release notes

FAQ

Why isn't it in the Mac App Store?

App Store apps run in a sandbox and can't scan or delete across your home folder. ZerX needs Full Disk Access to do its job, so it's distributed directly, signed and notarized by Apple.

Is it safe?

Deletion goes to the Trash by default. Personal data and system files are on a blocklist that the deletion layer enforces, and that layer is covered by tests. The source is on GitHub if you want to check.

What does Full Disk Access give the app?

Permission to read the folders macOS otherwise hides from apps, such as caches inside ~/Library. ZerX only deletes what you tick.

Can it clean "System Data" from Settings → Storage?

It shows what's inside that number — caches, logs, local Time Machine snapshots — and lets you remove the parts that are safe to remove.

Does it cost anything?

No. ZerX is free.

How do I uninstall?

Drag ZerX.app to the Trash. With Homebrew: brew uninstall --cask --zap zerx.
