# zerxapp.com

Website of [ZerX](https://github.com/VPNsafe/zerx), the macOS disk cleaner for developers, and the host of its Sparkle update feed. Static HTML + one CSS file + one tiny script, served by GitHub Pages from `main` / root. The spec lives in the app repository: `docs/TZ-site.md`.

## Layout

```
index.html              EN home
ru/index.html           RU home
privacy/index.html      EN privacy
ru/privacy/index.html   RU privacy
changelog/index.html    release notes (EN only)
download/index.html     meta-refresh redirect to the latest DMG
appcast.xml             Sparkle feed
404.html                served by Pages for unknown paths
assets/style.css        the only stylesheet, no build step
assets/site.js          "Copy" buttons only; the site works without JS
assets/                 logo.png, icon-512.png, icon-1024.png, og.png
favicon.ico, favicon-16.png, favicon-32.png, apple-touch-icon.png
robots.txt, sitemap.xml, CNAME, .nojekyll
```

Rules: no external requests of any kind (no CDN, fonts, analytics, iframes), every page carries a
`Content-Security-Policy` meta tag without `unsafe-inline`, so no inline `style=` or `<script>` blocks.
Every page exists in both `/` (EN) and `/ru/` with `hreflang` and `canonical` links, except
`changelog` and `download`, which are English-only.

## Who changes what

The **deploy agent** of the app repository touches exactly three files on every release and nothing else:

| File | Change | Commit |
|---|---|---|
| `appcast.xml` | regenerated by Sparkle's `generate_appcast` | `release: vX.Y.Z` |
| `download/index.html` | both URLs (meta refresh + visible link) → `https://github.com/VPNsafe/zerx/releases/download/vX.Y.Z/ZerX-X.Y.Z.dmg` | same commit |
| `changelog/index.html` | new `<h2>X.Y.Z — Month D, YYYY</h2>` + `<ul>` copied from the app's `CHANGELOG.md`, above the marker comment | same commit |

After editing `download/index.html`, check that both URLs are identical and point at `github.com/VPNsafe/zerx`:
`grep -o 'https://[^"]*' download/index.html | sort -u` must print exactly one line.

Everything else (pages, styles, graphics, texts) belongs to the **site-dev** agent. Texts are final and
change only together with `docs/TZ-site.md`.

## Screenshot slot

Both home pages contain `<figure id="screenshot" hidden>`. When `assets/screenshot-overview@2x.png`
(2560×1600 or a Retina window capture) is added, remove the `hidden` attribute on both pages and fix the
`width`/`height` attributes to half the pixel size.

## Local check

```bash
python3 -m http.server 8080
# then in another terminal
for p in / /ru/ /privacy/ /ru/privacy/ /changelog/ /download/ /appcast.xml /404.html; do
  printf '%-16s %s\n' "$p" "$(curl -s -o /dev/null -w '%{http_code}' http://localhost:8080$p)"
done
grep -rhoE 'https?://[^"<) ]+' --include=*.html --include=*.xml . | sort -u   # only github.com/VPNsafe, t.me/ZerXapp, zerxapp.com, andymatuschak.org (Sparkle namespace), sitemaps.org / w3.org (XML namespaces)
```

## Hosting

GitHub Pages, "Deploy from a branch", `main` / `/ (root)`, custom domain `zerxapp.com` (file `CNAME`),
"Enforce HTTPS" on once DNS has propagated. Also add `zerxapp.com` under GitHub → Settings → Pages → Verified domains for the
`VPNsafe` account, so the domain cannot be claimed by another Pages site if this repository is ever renamed or removed. DNS at the registrar:

```
A     @    185.199.108.153
A     @    185.199.109.153
A     @    185.199.110.153
A     @    185.199.111.153
AAAA  @    2606:50c0:8000::153
AAAA  @    2606:50c0:8001::153
AAAA  @    2606:50c0:8002::153
AAAA  @    2606:50c0:8003::153
CNAME www  vpnsafe.github.io
```

Check: `dig +short zerxapp.com` shows the four A records; `curl -sI https://zerxapp.com/appcast.xml` returns `200` with an XML content type and no redirect.
