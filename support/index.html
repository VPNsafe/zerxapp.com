ZerX Support

Developer: Viacheslav Kuzmin.

Install the Mac release

Get ZerX on the Mac App Store. Version 0.1.6 supports macOS 13 or later on Apple Silicon and Intel. Use the App Store release for public ratings and reviews; TestFlight is for beta feedback.

Windows beta 0.1.3

For Windows 11 x64, download the beta ZIP and read installation, publisher-signature and cleanup limits. Extract everything and run Install.cmd. No separate .NET download is required. Keep Windows security protections enabled if a warning appears; contact support if the publisher or signature is unexpected.

“Scan computer” inspects accessible fixed drives and reports unreadable areas. Cleanup is limited to manually selected aged Temp and recognized browser HTTP-cache files. Nothing is preselected; files go to the Windows Recycle Bin. Restore a file from the Recycle Bin if needed. ZerX does not empty it or offer permanent deletion on Windows. Switch English/Russian using the button in the window. Report Windows version, ZerX version and reproducible steps, with private paths removed.

Email support

For help with ZerX or privacy questions, email support@techdatacloud.org. Include your ZerX and operating-system versions and a description of the problem. Do not send passwords or sensitive file contents.

Report a problem on GitHub

Open a support request on GitHub (a GitHub account is required). Include your ZerX and operating-system versions, what happened and steps to reproduce it. Issues are public: remove personal paths, file names and other sensitive information from text and screenshots.

App news: ZerX Telegram channel.

Mac: file access and missing folders

Select your startup disk in the standard macOS file picker. ZerX scans files your account can read and reports unreadable areas instead of treating them as empty. No administrator privileges are required to scan. Full Disk Access is optional: it can include more protected files and reduce separate permission prompts, but does not remove every macOS restriction.

Open ZerX Settings → File Access to revisit setup. If you enable Full Disk Access in macOS System Settings → Privacy & Security, quit and reopen ZerX before scanning again.

Mac: restore a deleted file

If you used the Trash and have not emptied it, open it in Finder and choose Put Back for the file. Permanent deletion and emptying the Trash cannot be undone; recovery requires a separate backup if you have one.

Mac: change language

Select a language in ZerX Settings and relaunch the app. English, Simplified Chinese, Hindi, Spanish, French and Russian are supported.

Privacy and license

The privacy policy explains local storage and permissions. The App Store version uses Apple’s standard license agreement. See Safety for deletion rules.
