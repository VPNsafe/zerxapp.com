ZerX Support

Developer: Viacheslav Kuzmin.

Email support

For help with ZerX or privacy questions, email support@techdatacloud.org. Include your ZerX and macOS versions and a description of the problem. Do not send passwords or sensitive file contents.

Report a problem on GitHub

Open a support request on GitHub (a GitHub account is required). Include your ZerX and macOS versions, what happened and steps to reproduce it. Issues are public: remove personal paths, file names and other sensitive information from text and screenshots.

App news: ZerX Telegram channel.

Cannot access a folder

Open Settings → File Access and select the folder in the macOS dialog. Some system and protected folders remain inaccessible to the App Store version.

Restore a deleted file

If you used the Trash and have not emptied it, open it in Finder and choose Put Back for the file. Permanent deletion and emptying the Trash cannot be undone; recovery requires a separate backup if you have one.

Change language

Select a language in ZerX Settings and relaunch the app. English, Simplified Chinese, Hindi, Spanish, French and Russian are supported.

Privacy and license

The privacy policy explains local storage and permissions. The App Store version uses Apple’s standard license agreement. See Safety for deletion rules.
