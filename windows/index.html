ZerX for Windows beta

0.1.3 · First public Windows beta · October 27, 2026 · Free · Windows 11 x64

See which accessible files and folders occupy your fixed drives. Review a separate list of supported cleanup candidates and choose what to move to the Windows Recycle Bin. This beta has narrower cleanup features than the Mac version.

Install

  1. Download the ZIP and extract all its contents to a local folder.
  2. Run Install.cmd from the extracted folder. It launches the signed Install.ps1 script and installs for your Windows user, without an administrator prompt.
  3. Open ZerX using the installed shortcut. You can also run app\ZerX.exe directly from the extracted package.

The package includes its .NET runtime: no separate .NET download or SDK is required. Installation uses a versioned per-user directory and owned shortcuts; it preserves existing versions and user files. No service, driver or automatic updater is installed.

Publisher signature and download integrity

app\ZerX.exe, app\ZerX.dll, app\ZerX.Core.dll and Install.ps1 have verified Authenticode signatures from IE Viacheslav Kuzmin, using Certum code signing and timestamps. Check the publisher in Windows signature details.

The ZIP and Install.cmd batch launcher do not carry Authenticode signatures. This is not a signed EXE/MSI installer. Signing does not guarantee that SmartScreen warnings disappear. If Windows reports an unexpected publisher or an invalid signature, stop and contact support; keep Windows security protections enabled.

The checksum helps detect a damaged or different download; it does not independently prove publisher identity. The Windows prerelease is separate from the Mac App Store release.

Scan your computer

Choose “Scan computer” to inspect ready local fixed drives your account can read. Unreadable areas and other skips are reported, rather than counted as empty. A skipped directory can contain many files. Stop keeps partial results; closing the app cancels the scan.

Reparse points are not traversed and cloud-marked entries are skipped. A virtual or provider volume can report itself as a fixed drive; the provider may handle metadata requests and contact its service. Cloud recall behavior has not been fully validated.

Cleanup is a separate, manual step

  • Temp: only .tmp and .temp files in your canonical LocalAppData Temp folder, with both creation and modification times older than 30 days.
  • Browser HTTP cache: recognized disk-cache entries in standard Chrome, Edge and Firefox profiles under LocalAppData, with both timestamps older than seven days. Custom profile locations, indexes, cookies, passwords, history, sessions and site-storage databases are excluded.

Nothing is preselected. Review paths, tick items and confirm before moving them to the Recycle Bin. A running browser, including background processes, blocks its cache cleanup; inability to check running processes also blocks it. Cache content may need downloading again. An old file may still be useful.

System, read-only, encrypted, cloud, reparse, hard-linked and open files are excluded from cleanup. Paths, identity and timestamps are checked again before recycling; changed or unavailable files are skipped. Analysis categories never grant cleanup permission. These checks are not a proven boundary against a hostile process running as the same user.

Limits and recovery

ZerX does not empty the Recycle Bin or offer permanent deletion on Windows. Restore a recycled file there if needed. Files in the Recycle Bin still occupy space until you empty it yourself. Keep separate backups of important data.

Logical sizes include hard-link aliases; known allocated size covers only measured files and deduplicates supported identities. Largest folders overlap. These figures are not promised reclaimable space. Categories are approximate path/name groupings, not proof of ownership or cleanup recommendations.

System allocation, snapshots and filesystem metadata are not fully attributed. Results do not promise complete “System Data” coverage or equality with Windows Settings. The UI retains up to 100 largest files/folders; depth, identity and attribution limits can leave additional data unknown. ARM64, full accessibility and high-DPI validation, broader cleanup and updates remain future work.

Privacy, language and help

The Windows app reads filesystem metadata, not file contents, and has no network calls, telemetry or account. Cleanup probes access without reading file contents. Scan details stay in session memory. The interface starts in English or Russian according to Windows and can be switched in the window.

Read Privacy and Safety, or contact support. For Mac, use ZerX 0.1.6 on the Mac App Store.
