Privacy

Effective September 8, 2026

ZerX collects nothing. The app has no analytics, no crash reporting, no account and no network code, with one exception below.

Update check

It is off by default. If you turn it on, ZerX periodically downloads https://zerxapp.com/appcast.xml over HTTPS to learn whether a newer version exists. The request carries no identifiers and no system profile. Downloads come from GitHub Releases; GitHub's own privacy policy applies to those requests.

Full Disk Access

The permission lets ZerX read your folders to measure them. Nothing it reads leaves your Mac.

This website

No cookies, no analytics, no third-party scripts or fonts. It is hosted on GitHub Pages; GitHub may keep standard server logs under its privacy policy.

Contact

Open an issue on GitHub (zerx-releases) or write in the Telegram channel.
