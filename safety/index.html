Deletion rules and limits

These rules describe ZerX 0.1.6 from the Mac App Store. Scanning does not delete files. Review selected items before confirming removal: no cleanup tool can determine whether every file matters to you.

Mac: scan scope and deletion scope

Selecting the startup disk lets ZerX inspect files your account can read. Deletion remains limited to eligible items inside your home folder; system files and other users’ folders are outside that scope. macOS permissions still apply. Unreadable locations are reported, and their contents are not treated as empty.

Protected locations

ZerX blocks removal of these locations in your home folder, and of folders that contain them. This is a summary of the rules, not a promise that every personal file is automatically recognized.

  • ~/Library/Keychains, Preferences, Accounts, Messages, Mail, Photos, Cookies and Safari.
  • ~/Library/Mobile Documents and ~/Library/CloudStorage. CloudStorage is excluded from traversal. Cloud-only files are not a complete measure of local disk use.
  • Photo libraries matching ~/Pictures/*.photoslibrary and the music-library database at ~/Music/Music/Music Library.musiclibrary. This does not protect every photo, song or library stored elsewhere.
  • ~/.ssh, ~/.gnupg, ~/.aws, ~/.azure, ~/.kube, ~/.netrc, ~/.password-store and configured credential locations for Google Cloud, GitHub CLI, 1Password and Docker.
  • Listed shell configuration/history files and ~/.gitconfig; Xcode UserData and Templates.

Inside ~/Library, deletion is restricted to specific allowed locations, such as caches, logs and developer data, plus the exceptions below. Other Library locations remain protected.

Application Support exceptions

~/Library/Application Support is protected except for specific cache paths belonging to VS Code, Cursor, Discord, Slack, Spotify and Adobe, and individual iPhone/iPad backup folders under MobileSync. These exceptions require your selection. For supported apps with a running-app check, ZerX blocks cleanup until that app is closed.

Google Drive content caches are not a cleanup exception: they can contain unsynced changes. Manage cloud-sync storage in the owning application. An iPhone/iPad backup is personal recovery data, not a disposable cache; delete one only when you no longer need it.

Folder containers and path checks

Standard folders such as Documents, Downloads, Desktop and Library/Caches cannot themselves be deleted. Eligible contents can be selected individually. Every deletion passes through path checks, including a check after resolving symbolic links. These checks are covered by automated tests.

Trash and permanent deletion

Items move to the Trash by default. You can restore them in Finder while they remain there. Moving files to the Trash does not itself reclaim their disk space; empty the Trash only after checking its contents. Permanent deletion is a separate setting, off by default, and requires confirmation. It cannot be undone by ZerX.

The App Store version does not delete Time Machine snapshots. Its disk totals may differ from macOS Storage because of permissions, snapshots, shared APFS storage and other accounting differences. Keep a separate backup of important data.

Windows beta 0.1.3: separate cleanup rules

The macOS protections and permanent-deletion setting above do not describe Windows. Windows scans accessible fixed drives but only offers aged Temp files and recognized HTTP-cache files from supported browser profiles for cleanup. Nothing is preselected. Review each path and confirm recycling; scanning and analysis categories do not authorize deletion.

Windows cleanup excludes system, read-only, encrypted, cloud, reparse, hard-linked and open files. Running browsers or a failed process check block their cache cleanup. Paths, identities and timestamps are rechecked; changed or unavailable files are skipped. These checks do not prove protection from a hostile process running under the same account.

Files go only to the Windows Recycle Bin. ZerX does not empty it or offer permanent deletion on Windows. Recycled files still occupy disk space. Old files and caches may still matter to you; keep backups. Read the exact Windows scope, age thresholds, signing details and scan limits before using this beta.
