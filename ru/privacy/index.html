Конфиденциальность

Действует с 8 сентября 2026

ZerX ничего не собирает. В приложении нет аналитики, отчётов о сбоях, аккаунта и сетевого кода, с одним исключением ниже.

Обновления

Версия из App Store обновляется через App Store и сама запросов не делает. Прямая версия (планируется) проверяет обновления только если это включить: скачивает https://zerxapp.com/appcast.xml по HTTPS без идентификаторов.

Доступ к папке

При первом запуске вы выбираете домашнюю папку в стандартном диалоге macOS; это единственное место, где ZerX может читать и удалять. Ничего прочитанное не покидает ваш Mac.

Этот сайт

Без cookies, аналитики, сторонних скриптов и шрифтов. Сайт размещён на GitHub Pages; GitHub может хранить стандартные журналы сервера в соответствии со своей политикой конфиденциальности.

Контакт

Откройте issue на GitHub (zerx-releases) или напишите в Telegram-канал.
