Конфиденциальность

Действует с 29 сентября 2026

Разработчик и локальная обработка

Разработчик ZerX — Viacheslav Kuzmin. Версия App Store не передаёт разработчику имена и содержимое файлов, результаты сканирования или данные об использовании. В ней нет аккаунта, аналитики, рекламы и сервиса отправки отчётов о сбоях. Файлы обрабатываются на вашем Mac для подсчёта занятого места и удаления только после вашего подтверждения.

Доступ к файлам

Выберите домашнюю или другую папку в стандартном диалоге macOS. ZerX сканирует и очищает доступное содержимое выбранной папки с учётом ограничений песочницы и защиты macOS. Некоторые расположения остаются недоступны. Имена и содержимое файлов, а также результаты сканирования не отправляются разработчику. Чтобы выбрать другую папку, откройте Настройки → Доступ к файлам. Выход из ZerX завершает активный доступ в текущей сессии; сохранённое разрешение может использоваться при следующем запуске.

Хранение и удаление

Результаты сканирования находятся в памяти во время работы, заменяются последующими сканированиями и удаляются из памяти при выходе. Настройки, включая язык, и защищённая закладка папки сохраняются локально средствами macOS, чтобы приложение помнило ваш выбор. Они хранятся до сброса или локального удаления и никуда не загружаются. Удаление только ZerX.app может оставить настройки в контейнере macOS. За помощью в удалении локальных настроек обратитесь в поддержку.

По умолчанию файлы перемещаются в Корзину: их можно восстановить в Finder, пока Корзина не очищена. Безвозвратное удаление включается отдельно, по умолчанию выключено и требует подтверждения; отменить его нельзя. Удаление выбранных файлов и удаление настроек ZerX — разные действия. Разработчик не хранит аккаунт или серверную историю сканирования, которые нужно удалять.

Обновления

Версия App Store обновляется через App Store и сама не отправляет запросы обновлений. В планируемой прямой версии необязательная проверка обновлений выключена по умолчанию; при включении она запрашивает ленту обновлений на этом сайте. Хостинг может получать обычные данные соединения, например IP-адрес.

Этот сайт

На сайте нет cookies, аналитики, сторонних скриптов и внешних шрифтов. Сайт размещён на GitHub Pages. GitHub может обрабатывать данные соединений и журналы сервера согласно своей политике конфиденциальности; к этим журналам применяются его сроки хранения.

Поддержка и вопросы конфиденциальности

Контакт: support@techdatacloud.org. По этому адресу можно получить помощь, задать вопрос о конфиденциальности или запросить удаление переписки, которую вы передали нам.

Связаться с разработчиком по вопросам ZerX или этой политики можно через страницу поддержки. При обращении мы получаем информацию, которую вы сами передаёте для решения вопроса. Не включайте содержимое файлов или личные пути. GitHub Issues публичны. GitHub и Telegram обрабатывают сообщения по своим политикам: GitHub и Telegram. Сообщения могут оставаться в этих сервисах согласно их правилам и настройкам вашего аккаунта. ZerX не отправляет обращения автоматически.

Изменения

Обновления политики будут опубликованы здесь с новой датой вступления в силу.
