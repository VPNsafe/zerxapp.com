Правила и ограничения удаления

Эти правила относятся к ZerX 0.1.6 из Mac App Store. Сканирование не удаляет файлы. Перед подтверждением проверьте выбранное: программа очистки не может определить ценность каждого файла для вас.

Mac: область сканирования и удаления

Выбор загрузочного диска позволяет ZerX изучить файлы, доступные вашей учётной записи. Удаление ограничено разрешёнными элементами внутри домашней папки; системные файлы и папки других пользователей находятся за пределами этой области. Разрешения macOS продолжают действовать. Непрочитанные области отмечаются, их содержимое не считается пустым.

Защищённые расположения

ZerX блокирует удаление этих расположений в домашней папке, а также папок, которые их содержат. Это краткое описание правил, а не обещание автоматически распознать каждый личный файл.

  • ~/Library/Keychains, Preferences, Accounts, Messages, Mail, Photos, Cookies и Safari.
  • ~/Library/Mobile Documents и ~/Library/CloudStorage. CloudStorage исключена из обхода. Файлы, хранящиеся только в облаке, не отражают объём локально занятого места.
  • Медиатеки Фото по шаблону ~/Pictures/*.photoslibrary и база музыкальной медиатеки ~/Music/Music/Music Library.musiclibrary. Это не защищает все фотографии, песни и медиатеки, сохранённые в других местах.
  • ~/.ssh, ~/.gnupg, ~/.aws, ~/.azure, ~/.kube, ~/.netrc, ~/.password-store и предусмотренные правилами расположения учётных данных Google Cloud, GitHub CLI, 1Password и Docker.
  • Перечисленные в правилах файлы настроек и истории shell, ~/.gitconfig, папки UserData и Templates в Xcode.

Внутри ~/Library удаление разрешено только в определённых расположениях: например, кэшах, логах и данных разработки, а также в исключениях ниже. Остальные расположения Library защищены.

Исключения внутри Application Support

~/Library/Application Support защищена, кроме отдельных путей кэшей VS Code, Cursor, Discord, Slack, Spotify и Adobe, а также отдельных папок резервных копий iPhone/iPad в MobileSync. Эти элементы нужно выбрать самостоятельно. Для поддерживаемых приложений с проверкой запуска ZerX блокирует очистку, пока приложение не закрыто.

Кэши контента Google Drive не входят в исключения: в них могут храниться несинхронизированные изменения. Управляйте облачным хранилищем в самом приложении синхронизации. Резервная копия iPhone/iPad — личные данные для восстановления, а не ненужный кэш; удаляйте её, только если она больше не нужна.

Стандартные папки и проверка путей

Сами стандартные папки, например Документы, Загрузки, Рабочий стол и Library/Caches, удалить нельзя. Разрешённое содержимое можно выбрать по отдельности. Каждое удаление проходит проверку пути, в том числе после разрешения символических ссылок. Эти проверки покрыты автоматическими тестами.

Корзина и безвозвратное удаление

По умолчанию элементы перемещаются в Корзину. Их можно восстановить в Finder, пока они остаются там. Перемещение в Корзину само по себе не освобождает занятое ими место; очищайте её только после проверки содержимого. Безвозвратное удаление включается отдельно, по умолчанию выключено и требует подтверждения. ZerX не может его отменить.

Версия App Store не удаляет снимки Time Machine. Итоговые размеры могут отличаться от раздела «Хранилище» macOS из-за разрешений, снимков, общего хранилища APFS и других особенностей подсчёта. Сохраняйте отдельную резервную копию важных данных.

Windows бета 0.1.3: отдельные правила очистки

Защищённые расположения macOS и настройка безвозвратного удаления выше не описывают Windows. Windows сканирует доступные фиксированные диски, но предлагает для очистки только старые файлы Temp и распознанные файлы HTTP-кэша поддерживаемых профилей браузеров. Ничего не выбрано заранее. Проверьте каждый путь и подтвердите перемещение в Корзину; сканирование и категории анализа не дают разрешения на удаление.

Из очистки Windows исключены системные, доступные только для чтения, зашифрованные, облачные, открытые файлы, точки повторной обработки и файлы с жёсткими ссылками. Запущенные браузеры и ошибка проверки процессов блокируют очистку их кэша. Пути, идентичность и даты перепроверяются; изменённые или недоступные файлы пропускаются. Эти проверки не доказывают защиту от враждебного процесса той же учётной записи.

Файлы перемещаются только в Корзину Windows. ZerX не очищает её и не предлагает безвозвратное удаление на Windows. Файлы в Корзине продолжают занимать место. Старые файлы и кэши всё ещё могут быть нужны; сохраняйте резервные копии. Перед использованием бета-версии прочитайте точные ограничения Windows, сроки, сведения о подписи и сканировании.
