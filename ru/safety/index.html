Что ZerX никогда не удалит

ZerX видит всё внутри папки, к которой вы дали доступ, поэтому правила ниже работают на уровне удаления и покрыты тестами, а не спрятаны в интерфейсе.

Белый список области

Трогать можно только папку, к которой вы дали доступ, обычно домашнюю. Остальной диск показывается для картины, не для удаления.

Жёсткий чёрный список

Связки ключей, Preferences, Application Support, iCloud, Сообщения, Почта, Фото, Safari, .ssh, .gnupg, .aws, .kube, rc-файлы shell. Папка, внутри которой есть защищённый путь, тоже защищена.

Одна точка удаления

Каждое удаление проходит через единственную проверку: путь нормализуется и перепроверяется после разрешения симлинков. Симлинк в защищённую папку не пройдёт. Покрыто тестами.

Всегда защищено

  • ~/Library/Keychains
  • ~/Library/Preferences
  • ~/Library/Application Support (кроме кэшей приложений из списка ниже)
  • iCloud Drive (Mobile Documents)
  • ~/Library/CloudStorage (Google Drive, Dropbox, OneDrive)
  • Сообщения
  • Почта
  • медиатеки Фото
  • Safari
  • Cookies
  • ~/.ssh
  • ~/.gnupg
  • ~/.aws
  • ~/.kube
  • конфиги shell (.zshrc, .bashrc, .profile)
  • системный том и другие тома

Папка, внутри которой есть защищённый путь, тоже защищена.

Контейнеры: содержимое да, сама папка нет

Документы, Загрузки, Рабочий стол, Library/Caches и другие стандартные папки можно очищать по элементам, но сами папки удалить нельзя.

Кэши приложений, которые ZerX предлагает внутри Application Support

Кэш контента Google Drive, кэши VS Code и Cursor, Discord, Slack, Spotify, Adobe Media Cache, резервные копии iPhone (MobileSync). Каждый — отдельная галочка; если приложение-владелец запущено, ZerX попросит сначала его закрыть. Больше ничего внутри Application Support тронуть нельзя.

Корзина, дальше решаете вы

Всё уходит в Корзину. Очистка Корзины — отдельное явное действие. Локальные снимки Time Machine удаляются только в прямой версии, после запроса пароля администратора.
